# Changelog

## 0.1.0 (unreleased)

- Dialog-only roguelite run launched from Jangala: branching node graph with fog of war,
  Combat / Elite / Boss / Event / Shop nodes, Remnant boss.
- Temporary run fleet: pick a starting ship; the home fleet waits in the mothball bay and returns
  at run end. Each non-boss combat win offers 3 ships of the faction just fought, then a refit.
- Meta progression persists across runs (wins unlock starting hulls and start bonuses).
- Run intel entry shows depth, nodes ahead and meta stats.
